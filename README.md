📌 Project Overview
This project focuses on analyzing the Titanic Survival Dataset to understand the factors that influenced passenger survival. Using Python libraries, we perform data cleaning, exploratory data analysis (EDA), and data visualization to uncover meaningful insights from the dataset.

🎯 Objectives


Understand the structure of the Titanic dataset


Clean and preprocess missing and inconsistent data


Perform Exploratory Data Analysis (EDA)


Identify patterns affecting survival rates


Visualize insights using plots and charts



🛠️ Tools & Libraries Used


Python


Pandas – Data manipulation and analysis


NumPy – Numerical computations


Matplotlib – Data visualization


Seaborn – Statistical data visualization



📂 Dataset Information
The Titanic dataset contains passenger details such as:


Passenger Class (Pclass)


Name


Age


Gender (Sex)


Ticket Fare (Fare)


Cabin


Port of Embarkation (Embarked)


Survival Status (Survived)


Target Variable:


Survived (0 = Not Survived, 1 = Survived)



🧹 Data Cleaning
The following data cleaning steps were performed:


Handling missing values in Age, Cabin, and Embarked


Dropping unnecessary columns


Converting categorical variables into suitable formats


Checking and removing duplicates



🔍 Exploratory Data Analysis (EDA)
EDA was conducted to understand relationships and patterns:


Survival rate by Gender


Survival rate by Passenger Class


Age distribution of passengers


Fare distribution and survival comparison


Impact of embarkation port on survival



📊 Data Visualization
Visualizations were created using Matplotlib and Seaborn, including:


Bar plots


Count plots


Histograms


Box plots


Heatmaps for correlation analysis


These visualizations helped in clearly understanding trends and patterns in survival data.

📈 Key Insights


Females had a higher survival rate than males


Passengers in 1st class had better survival chances


Younger passengers were more likely to survive


Higher fare passengers generally had higher survival rates



🧠 Conclusion
This project demonstrates how data analysis and visualization techniques can be used to extract meaningful insights from real-world datasets. The Titanic dataset provides a strong foundation for understanding data preprocessing, EDA, and visualization using Python.
